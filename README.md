# Social Media Impact on Student Life — Power BI Dashboard

## 📊 Project Overview
This project explores social media usage patterns and their relationships with students' academic performance, sleep duration, stress levels, and mental well-being using Microsoft Power BI.

## 🎯 Objectives
- Analyze the most popular social media platforms.
- Explore daily usage patterns across age groups.
- Examine sleep duration by perceived social media impact.
- Compare stress levels across daily usage groups.
- Analyze academic performance and mental health indicators.
- Explore social comparison frequency.

## 🛠️ Tools & Technologies
- Microsoft Power BI Desktop
- Power Query
- DAX
- Data Visualization
- Data Analysis

## 📈 Dashboard Features
- KPI cards for key metrics
- Social media platform analysis
- Overall impact distribution
- Purpose-of-use analysis
- Daily usage by age group
- Sleep, stress, and academic performance analysis
- Interactive filters and slicers
- Dark neon-themed dashboard design

## ⚠️ Notes
The dashboard presents exploratory analysis. Relationships between social media use and outcomes should not be interpreted as proof of causation. Any purpose-of-use categories inferred from platform names are estimates rather than directly reported survey responses.
